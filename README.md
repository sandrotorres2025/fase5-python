# Control de Horas Trabajadas en Python

## Descripción

Este proyecto fue desarrollado en Python para solucionar el Problema 5 de la Evaluación Final.

El programa permite registrar las horas trabajadas por un equipo durante la semana utilizando una matriz.  
Además, calcula el total de horas trabajadas por cada recurso y determina si la jornada corresponde a horario estándar o sobretiempo.

---

## Objetivo

Desarrollar un sistema básico de control de horas laborales aplicando:

- Matrices
- Funciones
- Ciclos
- Condicionales
- Entrada de datos por teclado

---

## Funcionalidades

✅ Registro de 4 recursos  
✅ Ingreso de horas trabajadas de lunes a viernes  
✅ Cálculo automático del total semanal  
✅ Clasificación de jornada laboral  
✅ Visualización de resultados en pantalla

---

## Clasificación de Jornada

| Total de Horas | Clasificación |
|---|---|
| Mayor a 40 horas | Sobretiempo |
| 40 horas o menos | Horario Estándar |

---

## Tecnologías Utilizadas

- Python 3

---

## Estructura del Programa

El programa utiliza:

- Una matriz para almacenar la información
- Una función llamada `calcular_jornada()`
- Ciclos `for`
- Condicionales `if`
